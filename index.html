Simulation · WebGPU

Dendrite Garden

Dendrite Garden is an interactive, visual simulator of spiking neurons that runs in the browser. It simulates 5,000 to 100,000 neurons on the GPU, each with branching dendrites of up to 31 compartments. Synapses form where an axon passes close to a dendrite, and they strengthen, weaken and rewire while the network runs. One network, the Tadpole, has 30,000 neurons wired so that it swims, feeds and learns.

Single-cell RNA-seq · WebGL

scAnimator

scAnimator is a 3D viewer and animator for single-cell RNA-seq data that runs in the browser. It animates the UMAP as n_neighbors changes, so you can see how clusters hold together or split. You can colour and filter cells by any metadata, overlay any gene, record video up to 4K, and script a captioned walkthrough of a dataset. It works on datasets from a few thousand cells to a million, from AnnData or Seurat.

Image analysis · Python · napari

Dominion

Dominion is a napari tool for measuring cell morphology and tissue domains in immunofluorescence images. It finds each cell, divides the tissue into one domain per cell, and measures each domain's area, shape and intensity in every channel. It also traces cell skeletons, runs Sholl analysis and exports everything as CSV. I built it for astrocytes (GFAP and DAPI), and it works with any marker that is brightest at the cell.

Instruments · C++ · DSP

Ammonite

Ammonite is a family of arpeggiator synthesizers. You set a key, a chord progression and a rhythm for each part, and everything it plays stays in key and in time. Each version draws the music as it plays. There are three: a Windows app and plugin (VST3 and CLAP) with up to 16 channels and a 3D display, the original hardware synth with twelve knobs and a round screen, and an Android tablet app.
